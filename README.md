# alfred-RhymeZone 🎵

An [Alfred](https://www.alfredapp.com/) workflow to look up rhymes, near-rhymes, and
related words via [RhymeZone](https://www.rhymezone.com/).

## What it does

Trigger the keyword with a word to search RhymeZone. A configuration-only workflow
(no scripts) — it routes the query to RhymeZone.

## Notes

Personal workflow. Not published to the Alfred gallery.
